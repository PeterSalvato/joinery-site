Lesson 1.5: Decompose Your Own Work

Guided practice. Use a real prompt from your own work.

Lessons 1.1 through 1.4 demonstrated task decomposition on someone else's project. This lesson applies the method to your own work for the first time.

Pick one compound prompt from something you've actually worked on. Any domain, any project. The only requirement: it's a prompt you've used that asks for multiple things at once. Not a hypothetical. Something real.

The exercise

  1. Paste your compound prompt. The original, unedited.
  2. List every distinct task or dimension the prompt asks for. Number them. Be specific. "Give me a complete identity" is not one task. It's however many dimensions an identity has.
  3. For each task, write a standalone prompt. Address only that dimension. Give it only the context it needs. End each one with an explicit instruction to ignore the other dimensions.
  4. Run the compound prompt. Save the output.
  5. Run each decomposed prompt independently. Save the outputs.
  6. Compare. Where is the decomposed output deeper? Where does the compound output have better coherence? What conflicts exist between your decomposed outputs?

Document your comparison

  • Original compound prompt
  • Compound output (key excerpts — you don't need the whole thing)
  • Decomposed prompts (all of them)
  • Decomposed outputs (key excerpts from each)
  • Where the decomposed version went deeper — with specific examples
  • Where conflicts or tensions appeared between the specialist outputs
  • What you would synthesize differently from what the compound version decided

This is practice. The deliverable is Lesson 1.6, where you do the full cycle without a template. Save what you produce here — some of it may be worth using in your submission.
