Lesson 1.1: The Frame Break

Week 1 of 3. Six lessons. One deliverable.

You write a prompt. The output is close but flat. So you add detail. You specify tone, structure, audience, format. You add examples. The prompt grows to three paragraphs, then five. The output gets different, but it does not get better. It gets blurry. You add more constraints. The model starts contradicting itself. You conclude the tool is not capable enough, and you wait for the next version.

This is the most common experience practitioners have with AI. Almost everyone draws the wrong conclusion from it.

The problem is not the model. The problem is the question you're asking about the model. When output quality degrades, the instinct is to add more constraint: longer prompts, more detailed instructions, tighter formatting. The prompts grow. The output keeps degrading. Longer, more detailed prompts are not being more specific. They're overloading a single worker with a job that needs a team.

There is a different question: what does this system actually need to do this job well?

You already know how to ask that question. You do it every time you read a room. You read a client's decision-making style and shape the presentation to match. You read an audience's attention patterns and design the layout to hold them. You read a student's processing capacity and break the instruction into steps they can follow. That skill — reading the receiving system — has a name in this course: attunement. The design move that follows — adjusting your instruction to match what the system can actually receive — is accommodation. This week applies both to AI.

A large language model processing a compound instruction has processing limits. When you give it five objectives in one prompt, it distributes attention across all five, and each gets a fraction. The output comes back competent but shallow. The fix is the same one a good teacher applies when a student can only hold one instruction at a time: decompose. One objective per prompt. One specialist, one job.

This week you'll see why compound prompts degrade, watch what changes when you decompose the same brief, and do it yourself on your own work. By the end, you'll have done the full cycle: decompose, run the specialists, synthesize the outputs, and articulate what your judgment added that no combination of AI outputs could have provided.

The technique is straightforward. The skill underneath it is one you already have.
